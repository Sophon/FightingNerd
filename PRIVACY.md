# Privacy Policy for FightingNerd

**Last Updated:** 2026-03-08

## Overview

Fighting Nerd is a Discord bot and set of mobile apps that provide fighting game frame data and information. This privacy policy explains what data we collect and how we handle it.

## Collected Data

### General Bot Usage

When you use Fighting Nerd commands, **no personal data is collected or stored**. The bot simply:
- receives your command
- fetches the requested frame data
- responds in the channel

Error information may be temporarily logged for debugging purposes (see Error Logging section below).

### Command Usage Statistics

The bot tracks aggregate counts of command usage for operational purposes. This data is:
- anonymous — no user, server, or message identifiers are stored
- aggregate only — only a count per command type is recorded
- retained for 30 days in rolling daily summaries

## How Your Data is Used

**For all users:**
- anonymous, aggregate command usage statistics are collected to monitor bot health and feature usage
- error information may be temporarily captured for debugging (see Error Logging below)

### Error Logging
When the bot encounters an error processing a command, minimal debugging information is temporarily captured in platform logs:
- the command query that caused the error
- the server name

**Purpose:** Debugging and improving bot reliability  
**Retention:** Platform logs are retained for approximately 7 days, then automatically deleted  
**Access:** Only authorized developers can view logs  
**Not permanently stored:** This data is not saved to our database

**Your data is never:**
- shared with third parties
- used for advertising
- sold
- used for tracking

## Data Storage

**For general bot usage:**
- command usage statistics: anonymous aggregate counts retained for 30 days, then automatically removed
- for error logs: temporarily retained on hosting platform for ~7 days

## Third-Party Services

Fighting Nerd interacts with:
- **Discord API** - to send and receive messages
- **Game Wikis** - publicly available frame data or other FG related data is fetched from:
    - Wavu Wiki (Tekken)
    - SuperCombo (Capcom fighters, Mortal Kombat)
    - Dream Cancel (SNK fighters)
    - DustLoop (ArcSys fighters)
    - Infil Glossary

These services' privacy policies apply to their public data.

## Your Rights

You have the right to:
- **Access** - request what error log data may have been temporarily captured
- **Data minimization** - only minimal error information is captured
    - automatically deleted after 7 days

This privacy policy may be updated in the future.
