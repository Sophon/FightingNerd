# Privacy Policy for FightingNerd

**Last Updated:** 2025-12-19

## Overview

Fighting Nerd is a Discord bot and set of mobile apps that provide fighting game frame data and information. This privacy policy explains what data we collect and how we handle it.

## Data We Collect

### General Bot Usage

When you use Fighting Nerd commands, we **do not collect or store any personal data**. The bot simply:
- receives your command
- fetches the requested frame data
- responds in the channel

No user IDs, server IDs, or message content is stored.

### Optional Feature: EWGF

An **optional** registration feature is offered that allows you to:
- link your Discord ID with your Polaris ID (Tekken 8 player ID)
- store this association in our database for personalized features

**If you choose to register:**
- your Discord ID and Polaris ID will be stored
- you can unregister at any time using the `/unregister` command
- unregistering immediately deletes all your stored data from the database

**This feature is completely optional** - all other bot features work without registration and collect no data.

## How Your Data is Used

**For registered users only:**
- your Discord ID and Polaris ID association is stored to provide personalized features

**For all users:**
- No data collection or storage during normal bot usage

Your data is **never**:
- shared with third parties
- used  for advertising
- sold
- used for tracking

## Data Storage

**For registered users:**
- **Location:**: the database is hosted on Fly.io servers
- **Retention:**: your data is kept until you unregister
- **Security:**: reasonable security measures to protect stored data is implemented

**For general bot usage:**
- No data is stored

## Third-Party Services

Fighting Nerd interacts with:
- **Discord API** - send and receive messages
- **Game Wikis** - publicly available frame data or other FG related data is fetched from:
    - Wavu Wiki (Tekken)
    - SuperCombo (Capcom fighters, Mortal Kombat)
    - Dream Cancel (SNK fighters)
    - DustLoop (ArcSys fighters)
    - Infil Glossary

These services' privacy policies apply to their public data.

## Your Rights

You have the right to:
- **Access** - request what data we have about you (if registered)
- **Deletion** - use `/unregister` to immediately delete your stored data
- **Opt-out** - simply don't use the registration feature

## Changes to This Policy

We may update this privacy policy. Significant changes will be announced in our Discord support server.
